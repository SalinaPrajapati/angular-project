# Angular App

An Angular frontend workspace using standalone components, routing, and SCSS.

## Requirements

- Node.js 20.19 or later
- npm

## Run locally

```bash
npm install
npm start
```

Open the local address printed by Angular CLI. Create application routes in `src/app/app.routes.ts` and build features as standalone components under `src/app`.

## Production build

```bash
npm run build
```
