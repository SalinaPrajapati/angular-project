How are these fields protected?
  • Masked by default. The server sends only the last four characters. Full values are requested only when an authorised reviewer or admin chooses “Reveal”, are kept in memory only, and are hidden again after {{ revealSeconds }} seconds.
  • Role checks on the server. A Sales user who asks for the full values is refused, even if they bypass the interface.
  • Content Security Policy (CSP). This app tells the browser to run scripts and make network requests only to its own origin. If an attacker managed to inject a script or load code from another site (cross-site scripting), the browser would block it, so it could not read revealed values or send them away.
